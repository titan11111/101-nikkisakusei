# 仮想カンパニー 設定ファイル

## オーナー情報
- 事業・活動: 個人開発・ゲーム制作
- 目標: HTML5ブラウザゲームをGitHub Pagesで公開し、ポートフォリオを充実させる
- 公用語: 日本語

## 組織構成
- 秘書室（secretary）: 常設 — TODO管理・壁打ち・日次管理
- CEO（ceo）: 常設 — 振り分け・意思決定
- PM（pm）: ゲームプロジェクト進捗・マイルストーン管理
- 開発（engineering）: 設計書・デバッグログ・技術メモ
- クリエイティブ（creative）: ゲームアイデア・企画ブリーフ

## 部署フォルダ構成
```
.company/
├── CLAUDE.md          ← このファイル
├── secretary/         ← 秘書室（常設）
├── ceo/               ← CEO（常設）
├── reviews/           ← 週次レビュー（常設）
├── pm/                ← PM部署
├── engineering/       ← 開発部署
└── creative/          ← クリエイティブ部署
```

## 運営ルール
- 秘書が常にエントリーポイント。ユーザーは部署を意識しない
- 既存ファイルは上書きしない。追記または新規作成のみ
- ファイル名はkebab-case、日付ベースは YYYY-MM-DD
- CEOの意思決定は ceo/decisions/ にログとして残す
- 部署間連携が発生した場合、各部署のファイルに相互参照を記載する
